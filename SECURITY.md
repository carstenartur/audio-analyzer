# Security Policy

## Supported Versions

This project is currently in early development (0.1.x). Only the latest
snapshot version receives security fixes. No older versions are maintained.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities using [GitHub Security Advisories](https://github.com/carstenartur/audio-analyzer/security/advisories/new).
Do not open a public issue for security-related bugs.

When reporting, include:
- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant logs, stack traces, or proof-of-concept code

You can expect an acknowledgement within 5 business days. If the vulnerability
is confirmed, a fix will be prioritised and a patched release coordinated. If
the report is not accepted, you will receive an explanation.
